## Запросы

### 1. Получить названия треков, длительность которых больше 3 минут

**Реляционная алгебра:**

```text
π название (σ длительность > 180 (ТРЕК))
```

**Описание:**
Из таблицы `Трек` выбираются треки, длительность которых больше 180 секунд, после чего выводятся только их названия.

---

### 2. Получить название трека и название его исполнителя

**Реляционная алгебра:**

```text
ТРЕК ⋈ Трек.id_исполнителя = Исполнитель.id ИСПОЛНИТЕЛЬ
```

**Описание:**
Таблица `Трек` соединяется с таблицей `Исполнитель` по идентификатору исполнителя. В результате выводятся название трека и имя его исполнителя.
